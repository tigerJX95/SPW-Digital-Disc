# 首次出碟回归门禁

发布前单独运行首次出碟检查。用项目的正常构建流程编译插件后，把宿主归档路径传给测试脚本。

```sh
python3 tests/test_local.py /path/to/ffmpeg-x64.dll --first-reveal
```

Windows 可使用 `python`，并传入对应的 `ffmpeg-x64.dll` 路径。离线检查验证自定义盘面查找完成后会补做准备、换样式会准备新盘面，以及首个出碟帧会复用提前建立的绘制资源。离屏预热检查覆盖封面、生成盘面和倒影。另逐像素检查跳过完全裁掉的盘面倒影前后，显示结果一致。

在实机上分别确认以下场景。离线检查使用绘制替身，真实渲染的流畅度以实机结果为准。

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 首次安装 | 使用干净的插件配置安装并启用。播放一首没有自定义盘面的曲目，首次展开出碟 | 从封面放大到盘面露出连续，无明显停顿或跳帧 |
| 更换默认盘面 | 播放跟随全局默认、没有自定义盘面的曲目。收碟后切换默认样式，确认后立即展开。至少覆盖 CD、经典黑胶、彩胶、纯色卷盘和专辑封面卷盘，最后切回原样式 | 每次更换后的首次出碟与随后再次出碟一样连贯 |
| 自定义盘面 | 首次播放有可用自定义图片的曲目并展开出碟 | 直接显示自定义盘面，首次出碟连续 |

若实机仍有掉帧，可在 `reborn-cd-sample.log` 中对照首次出碟的 `FIRST_REVEAL_DRAW` 和 `ENTRY_SLOW_DRAW`。日志记录绘制总耗时和倒影绘制耗时，首次出碟还会记录盘面样式及是否使用自定义盘面。

首次出碟前若有 `RENDER_WARMUP`，且首条 `SELF_DRAW` 显示 `prepared=true`，表示离屏预热已经完成。`canvasLayer=true` 表示 Canvas 的独立绘制层已经挂载。

更换默认盘面时，`SETTINGS_RENDER_WARMUP` 记录后台预热的样式、目标尺寸和耗时。`DEFAULT_APPEARANCE_CHANGED` 的 `series` 与随后两次 `ENTRY_TIMING` 对应。用同一专辑和相同出碟量，确认后展开一次，收回后再展开一次。

保持旋转开启和出碟量 100，在同一首没有自定义盘面的曲目上，从专辑封面 CD 切到纯色拉丝银卷盘。确认后展开一次，收回再展开一次。记录 `REEL_RASTER_READY`，并确认 `FIRST_REVEAL_DRAW` 和 `ROTATION_FIRST_DRAW` 均显示 `reelRaster=true`。对照两次的出碟和起转，查看 `openingGapUs` 和 `hostFrameGapUs`。检查金属反光保持固定，窗口、磁带纹路和铭文随盘旋转，倒影及中心透明孔正常。

等首次出碟完成后，在封面保持展开的情况下切歌，再收回详情页并重新展开。从左侧点击封面时，封面应从点击前的位置边移动边放大，居中后出碟；保持详情页展开切歌时，复用原有出碟过程。可在放大途中点一次返回，确认封面连续回到原处。`COVER_HANDOFF moving=true` 记录起始横向、纵向偏移和比例。前两次完整进场各输出一条 `ENTRY_TIMING`，记录各阶段的 Canvas 绘制间隔、主动重绘次数、动画时钟间隔和绘制耗时。Canvas 回调时间与屏幕实际显示帧的时间有别。

在同一首歌上分别以出碟量 50、100 和 0 进入二级页。等出碟完成再点返回，有盘面时，封面应在收碟尾段开始缩小和平移，连贯回到一级页的原位。出碟量 0 时，封面直接缩小复位。也可点击正在平移的封面，确认点击区域随画面移动。同一首歌连续返回至少三次，逐帧观察倒影应从缩小期间贴着封面移动并逐渐延伸，到位后无明显跳变。检查放大到缩回的四角始终保持圆角，并确认缩回到位后有无几像素的突然横移或纵移。至少一次在收碟结束前把光标移到播放器外，确认交接位置。如果复现，保留录像和包含 `COVER_RETURN_HANDOFF` 的日志。

在同一窗口内，展开封面后连续切歌，再返回一级页。分别检查同专辑切歌和切到封面比例不同的曲目，确认封面仍平滑缩回原始显示区域。回位后逐帧检查原生界面接管。左侧小封面继续留在原处，尤其留意原生界面进入时封面是否再次跳回中央。也可用播放器返回操作触发同一路径。

`START` 行带有 `entryStart=sourceReady` 时，出碟在画面来源与布局就绪后开始。`ENTRY_TIMING` 的 `hostFrames` 和 `hostFrameGapUs` 记录进场动画使用的界面帧时钟次数和最大间隔。`hostFrames=0` 表示该次进场使用备用计时器。比较不同构建时，使用同一首歌和相同盘面、出碟量及旋转设置，对照 `openingGapUs`、`hostFrameGapUs` 和实机观感。

`discMirrorAtUs` 记录盘面倒影首次进入绘制范围的时间，以 `PRESENTATION_READY` 为起点，可和同一行的 `gapAtUs` 对照。

专辑封面 CD 会在封面过渡阶段后台准备完整盘面。用同一首歌，并保持出碟量、旋转和倒影设置一致，从卷盘切到专辑封面 CD 后打开一次，再收回重开。检查 `COVER_CD_RASTER_READY` 是否出现在 `FIRST_REVEAL_DRAW` 前。首帧和首次旋转的 `cdRaster=true` 表示同一张已合成 CD 用于出碟和旋转，主画面和倒影复用它。`cdRaster=false` 表示沿用实时绘制。自定义盘面仍优先。

彩胶和经典黑胶提前合成静止的盘面沟纹和反光。切换默认样式后，从首帧到旋转都应复用已准备的表面，中央封面继续独立旋转，彩胶保留半透明。分别检查首次切到彩胶和首次切到经典黑胶，再各自收回重开。日志含 `VINYL_SURFACE_RASTER_READY`，并在 `FIRST_REVEAL_DRAW` 和 `ROTATION_FIRST_DRAW` 中记录 `vinylRaster=true`。若盘面尚未备好，会连续使用实时绘制。保持倒影正常开启。
