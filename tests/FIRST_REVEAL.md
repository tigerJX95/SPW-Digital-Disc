# 首次出碟回归门禁

发布前单独运行首次出碟检查。用项目的正常构建流程编译插件后，把宿主归档路径传给测试脚本。

```sh
python3 tests/test_local.py /path/to/ffmpeg-x64.dll --first-reveal
```

Windows 可使用 `python`，并传入对应的 `ffmpeg-x64.dll` 路径。离线检查验证自定义盘面查找完成后会补做准备、换样式会准备新盘面，以及首个出碟帧会复用提前建立的绘制资源。离屏预热检查覆盖封面、生成盘面和倒影。另逐像素检查跳过完全裁掉的盘面倒影前后，显示结果一致。

在实机上分别确认以下场景。离线检查使用绘制替身，真实渲染的流畅度以实机结果为准。

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 首次安装 | 使用干净的插件配置安装并启用。播放一首没有自定义盘面的曲目，首次展开出碟 | 从封面放大到盘面露出连续，无明显停顿或跳帧 |
| 更换默认盘面 | 播放跟随全局默认的曲目。收碟后切换默认样式，确认后立即展开。至少覆盖专辑封面 CD、彩胶和开盘磁带 | 每次更换后的首次出碟与随后再次出碟一样连贯 |
| 自定义盘面 | 首次播放有可用自定义图片的曲目并展开出碟 | 直接显示自定义盘面，首次出碟连续 |

若实机仍有掉帧，可在 `reborn-cd-sample.log` 中对照首次出碟的 `FIRST_REVEAL_DRAW` 和 `ENTRY_SLOW_DRAW`。日志记录绘制总耗时和倒影绘制耗时，首次出碟还会记录盘面样式及是否使用自定义盘面。

首次出碟前若有 `RENDER_WARMUP`，且首条 `SELF_DRAW` 显示 `prepared=true`，表示离屏预热已经完成。`canvasLayer=true` 表示 Canvas 的独立绘制层已经挂载。

使用内置纯色开盘磁带时，`REEL_RASTER_READY` 表示背景位图已准备好，首次露出帧的 `reelRaster=true` 表示实际用了它。检查盘面、倒影和中心透明孔，并确认盘面开始旋转时固定光泽正常。

等首次出碟完成后，在封面保持展开的情况下切歌，再收回详情页并重新展开，对照连续出碟与重新放大封面的区别。接管时，封面应从宿主封面的尺寸居中放大。`COVER_HANDOFF` 记录宿主封面尺寸和插件的起始比例。前两次完整进场各输出一条 `ENTRY_TIMING`，记录放大、出碟和到达终点时的 Canvas 绘制间隔，以及主动重绘请求次数、动画时钟间隔和绘制耗时。Canvas 的回调时间与屏幕实际显示帧的时间有别。

`START` 行带有 `entryStart=sourceReady` 时，出碟在画面来源与布局就绪后开始。比较不同构建时，使用同一宿主、同一首歌和相同盘面、出碟量及旋转设置，对照 `ENTRY_TIMING` 的 `openingGapUs` 和实机观感。
